# 🎮 Simon Game – JavaScript

A browser-based **Simon Game** built using **HTML, CSS, and JavaScript**. The player has to remember and repeat the sequence of colored buttons. With every successful round, the sequence becomes longer and the difficulty increases.

## 📌 About the Project

This project is a classic implementation of the **Simon Memory Game** using vanilla JavaScript.

The game generates a random color sequence. The player must click the buttons in the same order as the generated sequence.

If the player correctly reproduces the complete sequence, the game moves to the next level. If the player clicks the wrong button, the game ends and the sequence is reset.

## 🎯 How to Play

1. Open the game in your browser.
2. Press any key to start the game.
3. The game will generate a random colored button.
4. Remember the color shown.
5. Click the button you remember.
6. Each successful round adds another color to the sequence.
7. Repeat the complete sequence in the correct order.
8. If you click the wrong button, the game is over.
9. Start again and try to beat your previous level.

## 🧠 How the Game Works

The game maintains two arrays:

```javascript
let gameSeq = [];
let userSeq = [];
```

### `gameSeq`

Stores the sequence generated by the game.

```javascript
gameSeq.push(radColor);
```

### `userSeq`

Stores the colors clicked by the player.

```javascript
userSeq.push(userColor);
```

The game compares both sequences using the `checkAns()` function.

```javascript
if(gameSeq[Ind] === userSeq[Ind]){
    // Correct answer
}
```

If the player completes the entire sequence correctly, the next level starts.

```javascript
if(gameSeq.length == userSeq.length){
    setTimeout(levelUp, 500);
}
```

If the player clicks the wrong button, the game ends and the game state is reset.
